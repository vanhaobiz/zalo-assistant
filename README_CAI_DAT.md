# Hướng dẫn cài Zalo Auto Assistant lên iPhone & Android (PWA)

1. Giải nén file `zalo_assistant_pwa.zip`.
2. Tải toàn bộ các file (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) lên một repository GitHub và bật **GitHub Pages** (hoặc Netlify / Vercel).
3. Mở đường link trang web vừa tạo trên điện thoại:
   - **iPhone (Safari):** Nhấn nút **Chia sẻ (Share)** -> chọn **Thêm vào MH chính (Add to Home Screen)**.
   - **Android (Chrome):** Nhấn dấu **3 chấm (⋮)** -> chọn **Cài đặt ứng dụng / Thêm vào màn hình chính**.

Sau khi thêm, ứng dụng sẽ có biểu tượng riêng trên màn hình chính, chạy toàn màn hình và lưu dữ liệu ngay trên điện thoại.
